# DuoTrace

DuoTrace helps League of Legends players find games that two Riot IDs have in common.

Enter two Riot IDs in the `GameName#TAG` format, choose their server region, and DuoTrace searches the match history Riot makes available. It shows each shared game’s queue, duration, champions, KDA, patch, and whether the players were on the same team or opposing teams.

Use the optional patch and month filters when you want to narrow the results.
